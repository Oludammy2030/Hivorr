## 3. Architectural and technical decisions

| Decision | Reason | Reversible |
|---|---|---|
| Fixed-window limiter | Simple, deterministic and testable | Yes |
| In-memory map | No new dependency; per-process is enough for EP-01 | Yes |
| Count successful sign-ins too | Limits the total attempt rate, not only failures | Yes |
| Config-driven thresholds | Per-environment tuning | Yes |
| Headers on `ApiError` | `Retry-After` without a special exception type | Yes |
| Every privileged sign-in audited | No location history exists; the row IP is the evidence | Yes |
