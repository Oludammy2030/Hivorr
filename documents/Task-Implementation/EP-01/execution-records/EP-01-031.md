## 3. Architectural and technical decisions

| Decision | Reason | Reversible |
|---|---|---|
| Capture-only email adapter | No provider credential exists; a real adapter replaces it without changing the service | Yes |
| Token lookup functions are security definer | The user cannot be known before the token is resolved; writes still use RLS | Yes |
| Token hash is SHA-256, raw token only in the message | The database never stores the bearer value | No |
| Reset revokes sessions rather than deleting refresh rows | Session revocation is checked on refresh; history is retained | Yes |
| Reset request always 202 | No account enumeration | No |
| Four endpoints added now | Recovery is part of the task, not `035` | Yes |
| Generation after contract change | The client and document stay in sync | Yes |
