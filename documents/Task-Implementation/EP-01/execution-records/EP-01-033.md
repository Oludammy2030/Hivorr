## 3. Architectural and technical decisions

| Decision | Reason | Reversible |
|---|---|---|
| Minimal transition table | The matrix defines states, not transitions; this is the narrowest coherent set | Yes, by ruling |
| Database trigger as backstop | The domain and database cannot drift silently | Yes |
| Deactivation from RESTRICTED/SUSPENDED allowed | A user may hide a restricted/suspended shell; it does not restore writes | Yes |
| Initial RESTRICTED/SUSPENDED forbidden | Platform states require an existing activation | Yes |
| List returns all six with `INACTIVE` for missing rows | The switcher needs the full registry | Yes |
| Composition controller outside modules | Direct identity↔profile imports create a cycle; the edge joins them | Yes |
| No verification query in activation | The expected outcome says activation is not gated | No |
