## 1. Implementation summary

One request pipeline now exists for every endpoint:

| Concern | Implementation |
|---|---|
| Audience declaration | `@Audience(...)` metadata, `AudienceGuard`, `declaredAudiences`, `isRoutedMethod` |
| Audience resolution | One resolver in `common/audience`, using `getPortalByHost` from the shared package |
| Validation | `parseBody` / `parseQuery`; every request schema is strict |
| Error contract | Nine stable codes, including `ACTIVITY_INACTIVE`; one filter maps every outcome |
| Pagination | Shared query schema/envelope; server cursor encode/decode and `toPage` |
| Idempotency | `Idempotency-Key` schema/parser, 24-hour TTL, canonical request fingerprint |

The guard fails closed: a route with no declaration is a 500 server defect, a wrong portal is a 403,
and a non-deployed environment is a 503. It resolves the forwarded host with the edge secret exactly
as the old request context did, and stores the resolved audience on the request so the context does
not resolve it twice.

**Duplication removed.** The server's private host table duplicated `PORTALS` in `@hivorr/shared`.
`resolveAudience` now uses `getPortalByHost`; `portal.ts` is a re-export so existing imports stay
valid. Controller-local validators were replaced with the common helper.

**Not claimed.** Pagination is a primitive, not yet applied to the two grant collections (`F-18`);
durable idempotency replay is not implemented (the table is ready); a handler execution deadline is
not implemented (`F-20`); capability declaration is `035`.

## 3. Architectural and technical decisions

| Decision | Reason | Reversible |
|---|---|---|
| Global guard rather than per-controller checks | API-04 applies to every endpoint; a new route cannot silently skip it | Yes |
| Undeclared route = 500 | A missing declaration is a server defect; default deny must not look like a client error | Yes |
| `public` audience for health | Probes are infrastructure, not a portal surface; naming it explicitly keeps the rule absolute | Yes |
| Handler metadata overrides class metadata | `GET /grants` serves all portals while the control routes serve only `control` | Yes |
| Keep `portal.ts` as a re-export | Avoids a broad import rewrite; one implementation remains | Yes |
| Strict zod schemas plus a central helper | SEC-23/API-06 require rejection, not stripping; one wording per failure | Yes |
| Field names in the error message, no zod detail | SEC-27 permits the field, forbids the internal reason | Yes |
| `ACTIVITY_INACTIVE` added to the shared contract | The task requires five distinguishable outcomes; four codes cannot express it | Yes |
| Pagination contract in shared, cursor codec in server | Clients need the envelope; only the server may mint/parse a cursor | Yes |
| Idempotency primitive stops at header + fingerprint | Durable replay must be written inside the owning transaction; a standalone store could record before commit | Yes |
| No global handler-timeout interceptor yet | It would affect future SSE and needs an explicit decision; recorded as `F-20` | Yes |
