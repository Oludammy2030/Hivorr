## 1. Implementation summary

Closed `F-40` by adding free-text scrubbing to the structured logger. Key-based redaction already removed credentials and named personal fields; it could not see PII embedded in a provider message. `scrubText` now removes email addresses, URLs, API keys, phone-like digit strings and long opaque tokens before the record reaches the sink.

## 3. Decisions

| Decision | Reason |
|---|---|
| Scrub only string values, not keys | Field names are useful for diagnosis; values carry the PII. |
| Keep UUID-shaped correlation IDs | The long-token rule excludes hyphens, so correlation IDs remain readable. |
| Redact URLs wholesale | A URL can carry a token in its query string; the path is not worth the leak. |
| Do not log raw provider messages | The API filter already avoids serialising raw errors; this closes the remaining string path. |
