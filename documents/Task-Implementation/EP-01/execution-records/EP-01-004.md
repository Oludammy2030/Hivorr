## 1. Implementation summary

The pipeline now represents every stage in `ARCHITECTURE.md` §12.2 and proves each blocking gate can
fail. Six gates were added or made explicit:

| Gate | Implementation | Blocks on |
|---|---|---|
| Contract | `pnpm test:contracts` (existing suite) | Vocabulary drift |
| Migration lint | `scripts/lint-migrations.mjs` | Bad name, destructive SQL without approval, new table without RLS, missing `lock_timeout` |
| Schema diff | `scripts/db-schema-snapshot.mjs` + `db-schema-diff.mjs` | Review artefact; optional `--fail-on-change` |
| OpenAPI diff | `scripts/openapi-diff.mjs` | Removed path/operation/response, new required input, type and enum narrowing |
| Visual regression | `scripts/visual-diff.mjs` + `scripts/lib/png.mjs` | Added, removed, resized or pixel-changed image |
| Seeded proofs | `scripts/test-ci-gates.mjs` | Proves typecheck, contract, migration, OpenAPI, visual and secret gates fail on bad input |

`ci.yml` gained a `gates`, `openapi`, `visual` and `ci-complete` job; `lint` gained migration lint;
`test` gained `test:contracts` and the previously missing `test:push-protection`; `database` gained
the migration lint, snapshot and diff summary. `ci-complete` depends on every gate job and fails if
any required job failed, was cancelled or was skipped.

**F-03 was ratified by the founder on 2026-11-09.** The custom boundary linter, custom migration
runner and lease-based outbox are the operative choices; they are no longer deviations.

**F-13 is recorded, not hidden.** The OpenAPI and visual gates have no real artefact until `013` and
`050`. They report themselves **dormant** with the owning task named. The seeded proofs show the
logic blocks; the real-artefact proof belongs to those tasks.

## 3. Architectural and technical decisions

| Decision | Reason | Reversible |
|---|---|---|
| **F-03 ratified**: keep `scripts/lint-boundaries.mjs`, the custom migration runner and the lease-based outbox | Founder ruling 2026-11-09. A working control is not replaced to match a stale line. | Yes, by a later ruling |
| Grandfather the eleven applied migrations in `lint:migrations` | §9.3 forbids renaming an applied migration; §9.4 cannot be retrofitted without editing applied SQL. New files are strict. | Yes |
| Seeded proofs are a script (`test:gates`), not comments in YAML | A gate that has never failed is not evidence; one command reruns every proof | Yes |
| OpenAPI and visual gates are **dormant**, not skipped silently | Avoids a false green; the job names the owning task (`013`, `050`) | Yes |
| Visual comparison is a dependency-free PNG decoder with a 0.1% pixel threshold | No new dependency; `050` may add tolerance or replace it with Playwright's comparator | Yes |
| Schema snapshot is derived output, never authoritative | Migrations remain the source of truth (§9.1); the snapshot is a review artefact | Yes |
| `ci-complete` is the single required status | GitHub Free cannot enforce required checks; the job still gives one honest status for the founder's review | Yes |
| No `upload-artifact` action added | Every action is SHA-pinned; no unused pin was fabricated. The job summary carries the snapshot and diff. `060` may add upload when the pin is resolved. | Yes |
| `test:push-protection` added to CI | It was part of `verify` but absent from `ci.yml`; the pipeline was weaker than the local gate | Yes |
