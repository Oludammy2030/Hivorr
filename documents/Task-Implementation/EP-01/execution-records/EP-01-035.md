## 3. Architectural and technical decisions

| Decision | Reason | Reversible |
|---|---|---|
| `requireCapability` in `common/errors` | One stable denial path | Yes |
| Activity check inside the write transaction | The expected outcome; no check-then-write gap | Yes |
| Context builder shared by session and audit | One mapping from rows to capabilities | Yes |
| Audit probe as a composition controller | It joins identity and platform without a module cycle | Yes |
| Audit read model in the platform module | Platform owns the table | Yes |
| No before/after payloads in the probe | Least data for a read-only probe | Yes |
