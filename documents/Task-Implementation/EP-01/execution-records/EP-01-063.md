## 3. Architectural and technical decisions

| Decision | Reason | Reversible |
|---|---|---|
| Smoke asserts anonymous denials | Proves the routes exist without a credential | Yes |
| Readiness accepts the honest 503 | The database probe is not implemented | When readiness lands |
| E2E verifies the slice bundle marker | A 200 fallback is not the deployed slice | Yes |
| Authenticated E2E is opt-in | No test identity exists; the skip is explicit | When an identity is provisioned |
| Promotion needs both jobs | A failed smoke/E2E blocks a release | Yes |
| Retry GETs | Fly scales to zero and wakes slowly | Yes |
