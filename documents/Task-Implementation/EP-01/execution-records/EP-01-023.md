## 3. Architectural and technical decisions

| Decision | Reason | Reversible |
|---|---|---|
| Add a comment migration rather than edit `005` | Applied migrations are immutable and checksum-protected | Yes |
| Assert schema properties statically and in the catalog | The static test names the contract; the DB test proves the live result | Yes |
| Treat `credentials` as the one `user_id` primary key | It is a one-to-one extension of `users`, not an entity with its own id | No |
| Require a comment on every identity table | An operator must not infer purpose from a name | Yes |
| Keep UUIDv7 and `timestamptz` | Project-wide convention from §9.4 | No |
