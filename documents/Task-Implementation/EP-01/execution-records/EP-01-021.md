## 1. Implementation summary

The migration runner, fresh-database test, lint and snapshot tools already existed. This execution
verified the contract and added the missing history verification:

| Property | Status |
|---|---|
| Advisory lock | `pg_advisory_lock(72700100)` in the runner |
| Per-file transaction | `begin` / `commit` around each migration; history row inserted before commit |
| History | `platform.schema_migrations(filename, checksum, applied_at)` |
| Checksum drift | A changed applied file is refused, never re-run |
| Idempotent second run | Files already present with the same checksum are skipped |
| Fresh database | `test:db` creates a temporary database, applies every file, asserts schemas/tables/roles/RLS |
| Lint | Naming, self-containment, destructive approval, RLS, lock-timeout; seeded proofs |
| History verifier | New `pnpm migrations:verify` compares files to `platform.schema_migrations` |

**Not claimed.** No committed `supabase/schema-baseline.txt` exists, so `db diff` is not clean
(`F-28`). No Postgres is available locally, so the runner, fresh-database test and history verifier
were not executed against a database in this session.
