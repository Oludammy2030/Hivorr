## 1. Implementation summary

The bootstrap code already existed and was mostly correct. Verification found one defect that made
the task's expected outcome impossible: **the compiled API could not resolve `@hivorr/shared`**. The
package exported `./src/index.ts`, and its compiled ESM used extensionless specifiers. A Node
process could therefore compile the server but never start it. The runtime image also omitted the
package entirely.

What changed:

| Area | Change |
|---|---|
| Shared runtime contract | `exports`/`types` point at `dist`; internal ESM specifiers carry `.js` |
| Server package graph | `server/package.json` declares `@hivorr/shared` instead of relying on a root hoist |
| Portal builds | `build:all` and `build:portals` build shared first; `vite.config.ts` aliases source for tests/dev |
| Runtime image | Dockerfile copies `packages/shared/package.json` and `dist` |
| Toolchain | Node floor is `>=22.12.0 <23`, the real requirement for `require()` of ESM |
| Evidence | New `tests/api-bootstrap.test.ts`, new `scripts/smoke-api.mjs`, new CI step, `verify` extended |

No controller, configuration schema, health route or correlation generator was duplicated. The
existing `app.ts`, `main.ts`, `config.ts`, health controller and pool were reused unchanged.

**Scope note on timeouts.** Fastify's `requestTimeout` bounds how long the server will spend
receiving a request from the client. It is not a handler execution deadline. The task's "request
timeouts" requirement is met at the transport layer; a handler deadline is not implemented and is
recorded as an open follow-up rather than claimed.

## 3. Architectural and technical decisions

| Decision | Reason | Reversible |
|---|---|---|
| Shared package compiles to **ESM**, not CommonJS | The portal builds need real named exports; a CommonJS `__exportStar` build failed Rollup with `MISSING_EXPORT` | Yes |
| Internal specifiers carry `.js` | Node ESM requires explicit extensions; TypeScript `bundler` resolution maps them back to `.ts` | Yes |
| Server requires ESM from CommonJS | Node 22.12+ supports `require(esm)`; this keeps one shared format instead of a dual build | Yes |
| Node floor tightened to `>=22.12.0 <23` | The declared floor previously included versions that cannot load the package | Yes |
| Tests and dev alias `@hivorr/shared` to source | The test job does not build; the alias keeps tests independent of build output while the smoke test still exercises the compiled path | Yes |
| Dockerfile copies the shared package | The runtime stage previously contained no copy of a module the server requires | Yes |
| Shared declared in `server/package.json` | It was a phantom dependency satisfied only by a root hoist | Yes |
| Process smoke is a separate script, not a Vitest file | It must exercise the compiled entry point and signals, not the test module graph | Yes |
| Invalid-config check requires both exit 1 and the failure message | Prevents a module-load crash from being mistaken for a configuration failure | Yes |
