## 3. Architectural and technical decisions

| Decision | Reason | Reversible |
|---|---|---|
| Playwright + bundled Chromium | Approved `EX-10`; one browser build for baseline and check | Yes |
| Pin the visual job to `windows-latest` | The baseline was captured on Windows; matching the OS preserves pixel identity | Yes, with a regenerated baseline |
| Capture from the production build | The gate must measure the built artefact, not the dev server | Yes |
| Fail closed on fonts | A silent fallback would create a false baseline | Yes |
| Block non-local requests | Removes analytics/asset variance without breaking the webfonts | Yes |
| Baseline scope = entry screens | Dashboard hero images come from Unsplash; a baseline must not depend on a third party | Yes, extend in `053` |
| Reuse `visual-diff.mjs` | Avoids a second comparator; it already supports zero tolerance | Yes |
| No artifact upload action | The CI contract allowlists only checkout/setup-node/pnpm; the committed baseline is the evidence | Yes |
