## 3. Architectural and technical decisions

| Decision | Reason | Reversible |
|---|---|---|
| Domain module imports no infrastructure | The task's engineering purpose is a pure invariant layer | Yes |
| Repository takes a transaction, not a pool | Every call shares the caller's unit of work and RLS context | Yes |
| Runtime schema guard | Defence in depth behind `lint-boundaries`; all SQL is static | Yes |
| Registration is the first adopted path | Proves the repository in a real flow with the smallest risk | Yes |
| Session/MFA/grant flows remain in the service | Their extraction belongs to `031`/`032`; a big-bang rewrite in a foundation task is unsafe | Yes |
| Re-export moved symbols | Avoids a broad import rewrite | Yes |
