The worker and outbox already existed. This execution verified them and added the missing evidence:

| Evidence | Added |

| Worker loop | `tests/worker-loop.test.ts` — claim, dispatch, replay, retry, dead-letter, lost lease, empty poll |

The implementation was reused unchanged: `worker.ts`, `OutboxRepository`, `OutboxWorker`,
`OutboxHandlers`, `retryDelayMs`, `startWorkerHealthServer`, and migration `011`. No queue table,
claim query, backoff function or health endpoint was duplicated.

**Contract preserved.** Delivery is at-least-once; handlers key by event id. An event whose type has
no handler is dead-lettered with `no handler registered for event type: ...`; it is never dropped.
Queue health returns counts and one timestamp, never a payload, aggregate id or credential.
