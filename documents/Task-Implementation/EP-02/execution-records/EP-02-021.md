## 1. Implementation summary

Added the narrow administration path for the taxonomy registry:

- security-definer functions for node and attribute create/update, gated on `admin.configuration.write`;
- a platform service that calls the functions and appends the audit record in the same transaction;
- control-audience endpoints for list, node create/update and attribute create/update;
- generated OpenAPI contract and client;
- a permission-aware `control.` taxonomy screen with node and attribute forms;
- contract, route-coverage and domain tests.

The API role still has no direct write grant on the taxonomy tables.
